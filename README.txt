المجلدات:
  pwa/              الملفات الستة للنسخة الويب (PWABuilder / استضافة HTTPS)
  android-project/  مشروع Android Studio كامل = الفقاعة خارج التطبيق + منبه دقيق

لماذا مشروع أندرويد؟
  الفقاعة التي تبقى ظاهرة فوق التطبيقات الأخرى مستحيلة في الويب/PWA،
  وتحتاج خدمة أصلية (BubbleService) وإذن «الظهور فوق التطبيقات».

بناء الـ APK (بدون كتابة أي كود):
  1) ثبّت Android Studio (Koala أو أحدث).
  2) File ▸ Open ▸ اختر المجلد android-project ثم انتظر انتهاء Gradle Sync (يحتاج إنترنت).
  3) Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s).
  4) الملف الناتج: app/build/outputs/apk/debug/app-debug.apk ثم ثبّته على الهاتف.

أول تشغيل (شاشة الصلاحيات):
  • الميكروفون ▸ سماح
  • الإشعارات ▸ سماح
  • الظهور فوق التطبيقات ▸ يفتح الإعدادات: فعّل OZAK ثم ارجع
  ثم اضغط «ابدأ الاستخدام». اخرج من التطبيق: ستبقى الفقاعة؛ اضغطها لتفتح نافذة الصوت.

هواتف Xiaomi / Huawei / Oppo / Samsung:
  فعّل لـ OZAK: «التشغيل التلقائي» + «بدون قيود البطارية» + «النوافذ المنبثقة أثناء التشغيل بالخلفية»،
  وإلا قد تقتل الشركة الخدمة وتختفي الفقاعة.

ملفات المشروع:
  MainActivity.kt   WebView + جسر Android للصفحة + التعرف على الصوت الأصلي
  BubbleService.kt  الفقاعة العائمة (سحب، انزلاق للحافة، شفافية وحجم من الإعدادات)
  AlarmScheduler.kt جدولة كل موعد بدقة (setAlarmClock)
  AlarmReceiver.kt  عند الموعد: يفتح التطبيق ملء الشاشة فيرنّ المنبه
  BootReceiver.kt   إعادة الجدولة وتشغيل الفقاعة بعد إعادة تشغيل الهاتف
  assets/index.html نفس واجهة OZAK
